[[overview]]
== 개요

알바 근무 스케줄 관리 서비스의 REST API 문서입니다. 모든 스니펫은 테스트 코드(Spring REST Docs)로부터 자동 생성되므로 실제 동작과 항상 일치합니다.

[[overview-auth]]
=== 인증 방식

* 불투명(opaque) 베어러 토큰 기반입니다. `POST /api/auth/login` 성공 시 토큰이 발급되며, 서버는 회원 정보를 암호화해 Redis에 저장합니다. 이후 요청은 `Authorization: Bearer <token>` 헤더로 인증합니다.
* 로그아웃(`POST /api/auth/logout`) 시 서버가 Redis에서 토큰을 삭제해 즉시 무효화합니다.
* 인증이 필요한 API에 미인증(토큰 없음/만료/무효) 상태로 접근하면 `401 Unauthorized` 를 반환합니다.
* 역할(Role)은 `OWNER`(사장)와 `PART_TIMER`(알바) 두 가지이며, 권한이 맞지 않으면 `403 Forbidden` 을 반환합니다.

[[overview-errors]]
=== 공통 에러 응답

모든 에러는 아래 형식을 따릅니다. `code` 는 프론트엔드가 분기에 사용할 수 있는 기계식 문자열입니다.

[source,json]
----
{
  "code": "STAFF_QUOTA_EXCEEDED",
  "message": "해당 시간대의 필요 인원(1명)이 이미 모두 배정되었습니다: 2026-05-10 09:00"
}
----

|===
| HTTP 상태 | 대표 code | 설명

| 400 | `VALIDATION_ERROR` | 요청 본문 검증 실패
| 401 | `AUTHENTICATION_FAILED` | 로그인 실패 / 미인증
| 403 | `NOT_GROUP_OWNER`, `NOT_GROUP_MEMBER` | 권한 없음
| 404 | `MEMBER_NOT_FOUND`, `GROUP_NOT_FOUND` | 리소스 없음
| 409 | `DUPLICATE_LOGIN_ID`, `SHIFT_NOT_AVAILABLE`, `STAFF_QUOTA_EXCEEDED` | 상태 충돌
|===
