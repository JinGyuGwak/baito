[[overview]]
== 概要

アルバイトのシフト管理サービスの REST API ドキュメントです。すべてのスニペットはテストコード(Spring REST Docs)から自動生成されるため、実際の動作と常に一致します。

[[overview-auth]]
=== 認証方式

* 不透明(opaque)ベアラートークンベースです。`POST /api/auth/login` の成功時にトークンが発行され、サーバーは会員情報を暗号化して Redis に保存します。以降のリクエストは `Authorization: Bearer <token>` ヘッダーで認証します。
* ログアウト(`POST /api/auth/logout`)時に、サーバーが Redis からトークンを削除して即座に無効化します。
* 認証が必要な API に未認証(トークンなし/期限切れ/無効)の状態でアクセスすると `401 Unauthorized` を返します。
* 役割(Role)は `OWNER`(オーナー)と `PART_TIMER`(アルバイト)の2種類で、権限が一致しない場合は `403 Forbidden` を返します。

[[overview-errors]]
=== 共通エラーレスポンス

すべてのエラーは以下の形式に従います。`code` はフロントエンドが分岐に使用できる機械的な文字列です。

[source,json]
----
{
  "code": "STAFF_QUOTA_EXCEEDED",
  "message": "この時間帯の必要人数(1名)はすでにすべて割り当てられています: 2026-05-10 09:00"
}
----

|===
| HTTP ステータス | 代表的な code | 説明

| 400 | `VALIDATION_ERROR` | リクエストボディの検証失敗
| 401 | `AUTHENTICATION_FAILED` | ログイン失敗 / 未認証
| 403 | `NOT_GROUP_OWNER`, `NOT_GROUP_MEMBER` | 権限なし
| 404 | `MEMBER_NOT_FOUND`, `GROUP_NOT_FOUND` | リソースなし
| 409 | `DUPLICATE_LOGIN_ID`, `SHIFT_NOT_AVAILABLE`, `STAFF_QUOTA_EXCEEDED` | 状態の競合
|===

[[assignment]]
== シフト割り当て (Assignment) — オーナー専用

[[assignment-assign]]
=== シフト割り当て

`POST /api/groups/{groupId}/assignments` — 時間範囲を30分スロットに分けて割り当てます。すべてのスロットが(勤務可能時間 + 必要人数)の条件を満たした場合のみ保存される all-or-nothing 方式です。

operation::assignment-assign[snippets='http-request,path-parameters,request-fields,http-response,response-fields']

必要人数超過の例(409):

operation::assignment-assign-quota-exceeded[snippets='http-response,response-fields']

[[assignment-cancel]]
=== シフト割り当て解除

`POST /api/groups/{groupId}/assignments/cancel` — 指定したアルバイトの確定した割り当てを時間範囲単位で解除します。範囲内で確定した割り当てがなかったスロットは無視されます。

operation::assignment-cancel[snippets='http-request,path-parameters,request-fields,http-response,response-fields']

[[assignment-list]]
=== シフト割り当て照会

`GET /api/groups/{groupId}/assignments?date=yyyy-MM-dd` — 割り当てられたアルバイトの名前 / ログイン ID も併せて返されます。

operation::assignment-list[snippets='http-request,path-parameters,query-parameters,http-response,response-fields']

[[assignment-candidates]]
=== 割り当て可能なアルバイト照会

`GET /api/groups/{groupId}/assignments/candidates?date=yyyy-MM-dd&startTime=HH:mm&endTime=HH:mm` — 選択した時間帯(必要人数ブロック)のすべての30分スロットを勤務可能時間として登録している有効なメンバー一覧を返します。`alreadyAssigned=true` のメンバーはすでにその時間帯すべてに割り当て済みのため、選択不可として表示する必要があります。

operation::assignment-candidates[snippets='http-request,path-parameters,query-parameters,http-response,response-fields']
